# Рисёрч по Hearthstone

Задача — принести свежие факты с источниками и подать их авторским голосом, а не пересказом ленты.

Правило, отделяющее этот скилл от редактуры: **сначала факты и ссылки, потом стиль**. Собранное — материал, а не готовый текст.

## Что реально доступно

Проверено, не по памяти:

| Источник | Как берётся | Ограничение |
|---|---|---|
| Веб-поиск | `WebSearch` | Основной инструмент. Даёт свежие данные, знает текущее дополнение |
| Мета-сайты | `WebFetch` по hsreplay.net, hearthstonetopdecks.com, metastats.net, vicioussyndicate.com | Работает |
| Reddit | `scripts/collect.py reddit` (RSS old.reddit.com) | JSON-API отдаёт 403, прямой `WebFetch` заблокирован. RSS упирается в 429 — запросы идут по одному с паузой |
| YouTube | `scripts/collect.py youtube` (разбор выдачи поиска) | Названия, каналы, даты, просмотры, описание. Расшифровок роликов нет |
| X / Twitter | только `WebSearch` с `site:x.com` | Прямой доступ закрыт: API платный, nitter мёртв. Сам скрипт X не берёт |

Если источник не отдался — так и сказать. Не пересказывать по памяти под видом свежего и не выдумывать цифры.

## Порядок

### 1. Уточнить вопрос

Что именно нужно: состояние меты, конкретный архетип, реакция сообщества на патч, материал для статьи, проверка одного факта. От этого зависит набор источников — тащить всё подряд не надо.

Спросить, только если без ответа работа пойдёт в другую сторону.

### 2. Собрать

Сначала веб-поиск — он быстрее всего даёт картину и текущее дополнение:

```bash
# WebSearch: "hearthstone meta tier list <месяц год>"
# WebSearch: "hearthstone patch notes <номер>"
# WebSearch: "<архетип> deck guide site:reddit.com"
```

Дальше — прицельно по источникам:

```bash
python3 .claude/skills/hs-research/scripts/collect.py reddit --sub CompetitiveHS --sort top --time week
python3 .claude/skills/hs-research/scripts/collect.py reddit --sub hearthstone --query "нужное" --time month
python3 .claude/skills/hs-research/scripts/collect.py youtube --query "best decks" --recent
python3 .claude/skills/hs-research/scripts/collect.py all --query "тема"
```

Reddit отвечает `429`, если дёргать его часто. Это нормально: подождать минуту и повторить, а не считать источник мёртвым.

Полезные точки входа: r/CompetitiveHS (аналитика и отчёты vS Data Reaper), r/hearthstone (реакция широкой аудитории), r/wildhearthstone, r/BobsTavern (Battlegrounds), hsreplay.net (проценты побед), vicioussyndicate.com (еженедельный отчёт).

### 3. Проверить

Прежде чем нести факт в текст:

- **Дата.** Hearthstone меняется патчами; материал месячной давности может быть уже неверным. У каждого факта — дата и, если есть, номер патча.
- **Два источника на спорное.** Процент побед из одного поста — мнение. Тот же процент в отчёте vS — факт.
- **Ранг и выборка.** «54% побед» на золоте и в топ-легенде — разные утверждения. Тащить условия вместе с числом.
- **Мнение против данных.** Тред на реддите — это настроение сообщества, а не статистика. Так и называть.

### 4. Подать в авторском стиле

Взять `ГОЛОС.md` из корня папки — он заполнен по корпусу из 49 гайдов автора.

Что значит «в стиле»:

- длина и разброс предложений, степень разговорности, любимые связки — из `ГОЛОС.md`;
- термины — по словарю в `CLAUDE.md` (колода, а не дека; процент побед, а не винрейт);
- названия карт и архетипов — как в источнике, без кавычек и без перевода;
- **ОТК** и **возвещение** — неизменны.

Что стилизация не отменяет:

- **числа и цитаты не меняются** ради красивой фразы;
- ссылка на источник стоит рядом с фактом, а не свалена в конец;
- своё мнение отделено от данных — если оценка авторская, это должно быть видно;
- английские названия и цитаты не переводятся вольно.

Дальше готовый текст проходит через `hs-edit`: маркеры, ритм, финальный чеклист. Свежесобранный материал особенно легко выходит шаблонным — «мета продолжает развиваться», «время покажет», «эксперты сходятся».

### 5. Отдать

Порядок ответа:

1. **Текст** — готовый материал в авторском стиле.
2. **Источники** — ссылками, с датами. Каждая цифра должна прослеживаться.
3. **Дыры** — чего добыть не удалось, что противоречиво, что стоит перепроверить перед публикацией.

## Нерушимое

1. Никогда не выдавать знание по памяти за свежие данные. Не нашлось — так и сказать.
2. Никогда не выдумывать процент, дату, патч, ник или цитату.
3. Никогда не переводить название карты, если официального русского варианта нет в исходнике.
4. Никогда не подавать мнение из треда как статистику.
5. Никогда не имитировать авторский стиль наугад — при пустом `ГОЛОС.md` писать нейтрально и сказать об этом.
6. Никогда не терять привязку числа к дате, патчу, рангу и размеру выборки.
